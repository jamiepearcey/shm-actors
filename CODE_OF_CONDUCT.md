# Code of conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be professional, be specific, critique code and claims — never
people. Benchmarks settle performance arguments; ADRs settle design arguments;
nothing settles arguments about tone except dropping it.

Report unacceptable behavior through the same private channel as
[SECURITY.md](SECURITY.md); reports are handled confidentially.
