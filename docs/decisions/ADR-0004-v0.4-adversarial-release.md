# ADR-0004 — v0.4: the Adversarial Release

- Status: Accepted
- Date: 2026-07-23
- Decider: architecture (Fable 5), transcribed by implementation
- Builds on: [ADR-0003](ADR-0003-v0.3-scope.md)

## Context

v0.1–v0.3 delivered the four primitives, cross-process borrowing, and
crash-correctness (v0.3 "hostile cache loop": kill-9 reader mid-pin + writer
mid-write + zero-leak census). But the lock-free cores are verified only by
stress tests + two scripted kill-9s; the two untrusted-input parsers (UDS wire
codec, Arrow BatchHeader/manifest) are unfuzzed; and the prod OS (Linux, with the
futex/memfd/pidfd fast paths) is unbuilt/untested. That is the credibility gap
for a substrate — not performance.

## Decision

A substrate's product is **trust**. v0.4 makes it adversary-proof, not faster.

### Scope

**IN: P, M, N, L, O, Q. OUT (v0.5+): H, R, S, G, I, the §6 runtime API.**

- **P** — Linux CI: build+test the existing POSIX paths on Linux.
- **M** — miri + ThreadSanitizer over the unsafe pointer / `from_custom_allocation`
  code, in CI.
- **N** — fuzz the two untrusted parsers (UDS codec + BatchHeader/manifest);
  fix findings.
- **L** — model-check the four lock-free cores (pin hazard handshake, Treiber
  free-list, RCU retire, task-claim CAS) under `loom`, by abstracting the atomic
  substrate so the *algorithm* runs on `loom::sync` in ordinary memory.
- **O** — broaden crash injection: kill-at-every-state-transition matrix,
  coordinator death, torn writes, a churn soak with periodic zero-leak census.
- **Q** — an ArrowRef integration **spike** on the smaller **task-fabric**
  surface, output = a migration ADR + API-gap list feeding v0.5.

Cut-line rationale: Q is in because it is the cheapest way to learn which Tier-3
perf item actually matters (suspected: R, the Append O(table) fix) — get
evidence, don't guess. H/R/S/G/I and the ergonomic Actor/Ctx runtime slip:
perf/feature/ergonomics work before a real consumer is speculation.

### Sequence (one agent per stage; infra may batch)

1. **P** — Linux CI (pure-additive; precondition for the rest).
2. **M** — miri + TSan in CI (pure-additive).
3. **N** — fuzz harnesses + corpus; fixes touch parser code only.
4. **L** — atomic-substrate abstraction + loom harnesses. **The one product-code
   refactor**; lands after 1–3 so CI+sanitizers guard it. Not concurrent with
   anything.
5. **O** — crash matrix + soak, against post-L code.
6. **Q** — ArrowRef task-fabric spike → migration ADR.

### The v0.4 proof

v0.3 proved survival of hostile *crashes*. v0.4 proves survival of **adversarial
scheduling** (loom on all four cores), **adversarial bytes** (fuzzed parsers,
zero crashes), **adversarial timing** (kill-at-every-transition + soak, zero-leak
census), **on the prod OS** (green Linux CI) — and carries **one real ArrowRef
workload**.

### ABI / refactor rulings

- **L**: zero on-shm change. `#[repr(transparent)]` newtypes (`ShmAtomicU64`
  etc.) in a `substrate` module; `cfg(loom)` swaps in a `loom::sync` twin used
  only by model-harness crates that re-instantiate the algorithm in ordinary
  memory. Any descriptor/POD layout change is rejected outright.
- **H** (deferred): impls only; any new `Platform` method gets a POSIX-fallback
  default. The doorbell word is already ABI-reserved — nothing to do now.
- **Q**: lives in **ArrowRef's repo** against shm-actors' published API.
  shm-actors stays clean-room — no ArrowRef dep, ever; gaps return as the ADR,
  not as code here.

### Explicitly NOT yet

- **R/S** — wait for Q's evidence on which perf shortfall a real workload hits.
- **H** — needs P first; the µs idle wakeup is unproven as a bottleneck.
- **§6 Actor/Ctx runtime API** — designing ergonomics before the first consumer
  (Q) is how APIs go wrong.
- **G/I, Dictionary/Union/Map** — no consumer demands them yet.

## Environment note (implementation)

Dev box is macOS/Apple Silicon. Probed available: nightly toolchain,
`cargo-fuzz 0.13.1`, `loom` (stable). `miri` not yet installed (addable via
`rustup component add miri`). Linux CI is authored but can only be exercised on a
Linux runner (no remote configured); everything else is runnable locally.
