# ADR-0003 — v0.3 scope, sequence, and the hostile cache loop

- Status: Accepted
- Date: 2026-07-22
- Decider: architecture (Fable 5), transcribed by implementation
- Builds on: [ADR-0002](ADR-0002-v0.2-scope.md)

## Context

v0.1 + v0.2 are delivered and green (6 crates; the v0.2 "cache loop" proves
commit→VersionEvent→doorbell-parked watcher→task→worker pin→DONE across
processes, with two `kill -9` scenarios). The remaining deferred set plus two
crash-correctness holes surfaced during v0.2 form the v0.3 candidate set (E–K).

## Decision

Theme: **"kill -9 anywhere, nothing leaks, nothing wedges — with real Arrow
tables."** Correctness holes and load-bearing capability in; perf polish out.

### Scope

**IN v0.3: J, K, E, F, and the segment_id widen (done now). OUT (v0.4+): H, G, I.**

- **J** — cross-process artifact-pin crash reclamation. The only remaining
  unrecoverable leak: a `VersionPin` leaked by a `kill -9`ed reader/worker pins a
  version's chunks forever. A substrate that can pin chunks forever is not a
  foundation.
- **K** — coordinator-backed artifact write lease. The only remaining permanent
  wedge: a dead exclusive writer leaves `writer_owner` stuck. Small; reuses the
  lease monitor.
- **E** — cross-process schema coordinator. "Both sides seed identical
  registries" is a coordination bug waiting for ArrowRef's first schema
  evolution.
- **F** — multi-chunk / sliced / nested Arrow batches. ArrowRef needs
  Struct/List and >1-chunk batches; without F the substrate only proves toys.
- **segment_id widen** — ABI breaks only get costlier; v0.3 already breaks ABI,
  so batch it.
- **H** OUT — behind the `Platform` seam, correctness-identical by definition,
  untestable on the macOS dev box; lands cleanly in v0.4. Its on-shm ABI is
  *pre-reserved* in S0 (see below).
- **G** OUT — wasteful-but-correct is exactly what defers.
- **I** OUT — feature expansion, nobody blocked.

### Sequence (one agent per stage, strictly ordered)

0. **S0 — ABI-break batch** (`shm-core`): widen the `PackedRef` segment_id so
   artifact data-segment ids are not capped at 2^16 (repacking ruled separately —
   see ADR-0003a); add a reserved 32-bit doorbell-sequence word to the ring/task
   control blocks so v0.4's futex lands ABI-compatibly. Everything rebuilds on
   this — must be first.
1. **S1 — J**: extend `BorrowJournal` with an `ArtifactPin{artifact_id, version}`
   entry kind; lease-monitor replay decrements the per-version pin table. One
   reclamation mechanism, never two — the pin table stays truth, the journal is
   the crash ledger. ABI-touching (journal slot format).
2. **S2 — K**: `writer_owner` becomes `{owner, fence_generation}`; coordinator
   lease death CAS-releases it with fencing. Minor ABI touch (`ArtifactHead`).
3. **S3 — E**: coordinator-issued `schema_id`s over UDS, nodes cache locally;
   the deterministic content-hash is retained as the interning key. **No shm
   schema-catalog region in v0.3.** Pure additive (protocol only). Must precede
   S4 so nested schemas flow through it.
4. **S4 — F**: multi-chunk / sliced / nested support in `shm-arrow`; versioned
   `BatchHeader` bump; manifests unchanged (already multi-chunk). ABI touch is
   in-chunk only.
5. **S5 — proof** (below).

### v0.3 walking skeleton — "the hostile cache loop"

Producer commits a **multi-chunk Struct/List** artifact version under a
**coordinator-negotiated schema** → a reader pins it, **`kill -9` mid-pin** →
journal replay unpins; the version is superseded; chunks provably reclaimed → an
**exclusive** writer takes the lease, **`kill -9` mid-write** → the lease monitor
fences and releases; a second writer commits successfully. Assert **zero chunk
leakage** by a pool census at the end.

### ABI rulings

- **J** extends `BorrowJournal` (one reclamation mechanism). `ChunkDesc.schema_id`
  stays u32.
- **H** changes nothing on-shm *provided* S0 reserves the doorbell word — that
  reservation is the only H work in v0.3. `Platform` trait unchanged.
- **E** `ChunkDesc.schema_id` stays u32; semantics change local-deterministic →
  coordinator-issued. No layout change.
- **F** `BatchHeader` breaks (versioned); manifest untouched.
- **segment_id** widened now, not deferred. Repacking mechanism in ADR-0003a.

### Classification

| Item | ABI |
|---|---|
| S0 widen + doorbell word | breaks frozen ABI |
| J | touches frozen ABI (journal slots) |
| K | minor touch (`ArtifactHead`) |
| E | pure additive (protocol) |
| F | touch (`BatchHeader` only, versioned) |
