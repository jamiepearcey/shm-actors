One copy in.
Zero copies after.

shm-actors is a cross-process actor substrate where a payload is written once into shared memory and everything downstream — pub/sub, tasks, streams, versioned tables — moves a 24-byte descriptor. Rust's borrowing, extended across process boundaries: exclusive loans for writers, pinned shared views for readers, and crash reclamation that provably leaks nothing.

The unit of conversation: one 64-byte envelope — one cache line, frozen ABI, #[repr(C, align(64))] hover a field ↓
The payload never rides in the message. payload carries a packed reference into the shared pool; version pins the exact table version it was committed at.
The model

A control plane that never touches the data path

coordinatorregistry · leases · fd passing · reclamation
──SCM_RIGHTS──▶segment fds, once
actor Amaps segments, then: no hot-path syscalls
◀─shared memory─▶descriptors only
actor Bordinary Rust process

The coordinator owns names — topics, artifacts, actors, leases — hands segment file descriptors over a Unix socket, and drives crash reclamation. It is never on the data path: if it dies, existing channels keep flowing. Actors are plain Rust processes that map the granted segments and then communicate entirely through shared memory.

shm-ring Pub/sub

SPMC broadcast ring with per-subscriber cursors. One-way hop: 83.5 ns p50, cross-process — the same as cross-core.

Fault tolerance

The crash story, measured — not promised

The demo's supervisor injects _exit(137) into a pricer while it holds a claimed task and a journaled pin. What follows is mechanical:

t = 0pricer killed mid-message
▶lease runs out
t = 500 mscoordinator fences the corpse, replays its journal
▶task redelivered
t ≈ 530 mssuccessor's first reply
▶census
0 leakedpool returns to baseline, to the chunk
  • 1 restart, 1 redelivery, 0 lost, 0 errors — clients see replies from both incarnations; the reply carries the exact attempt count.
  • The dead process's journaled pin and staged chunks are replayed, its lease fenced — a zombie waking later can never write into freed memory.
  • The recovery constant is the lease, not luck: 500 ms lease → 522–543 ms to first successor reply, run after run.
Why trust it

Adversarial by policy

239 tests that attack

Lineage races, crash replays, and exact-census invariants: count the free chunks after every hostile scenario and the difference must equal the live data — to the chunk.

4 loom models

The pin hazard handshake and the one-election reclaim CAS are exhaustively model-checked — and shown to fail against deliberately broken orderings.

5 fuzz targets

Every untrusted-input parser: manifest bytes, chain walks, Arrow layout, wire protocol. Plus a 200 000-iteration in-crate property test so the guarantee holds on stable.

Frozen, asserted ABIs

const offset assertions on the envelope, magic + generation checks on every dereference, torn-tail-tolerant journals.

Wording rules are part of the engineering: “zero-copy” is defined, the timer floor is named, memcpy throughput is not called ingestion, no comparison baseline exists so no “N× faster than X” is claimed, and a bench that can't distinguish two designs is replaced rather than quoted.
Get started

Run it in three commands

# build + the full adversarial test suite
cargo build && cargo test --workspace

# measured numbers on your machine (prints its own hardware profile)
cargo run -p shm-bench --release -- all

# the Holon demo: curve publisher, pricer + risk actors, clients,
# and a supervisor that kill -9s a pricer mid-message
cargo run -p holon-demo --release -- bench
