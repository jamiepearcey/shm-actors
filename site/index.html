Actors own no state.
Memory owns no code.

Holon is an actor framework where the message is a 64-byte envelope, the payload lives in a versioned Arrow cell in shared memory, and a handler pins the exact version its message names. Actors are ordinary Rust processes; a kill -9 mid-message recovers by lease and journal replay with zero losses. It stands on shm-actors, the zero-copy substrate: one copy in, everything downstream moves a 24-byte descriptor.

The framework

Message loops over shared state, without sharing mutable state

An actor is a handler behind a mailbox. Envelopes ride a lock-free task queue; dispatch is a sorted table of function pointers — no dyn, no allocation on the message path. One process hosts any number of actors over one mailbox, routed by the envelope's to; N processes of the same name form a pool with lease-based failover.

// host side: any number of actors, one mailbox, routed by `to`
let mut sys = ActorSystem::attach(&node)?;
sys.spawn("pricer", Pricer::new(curve_ref))?;
sys.spawn("risk",   Risk::new(curve_ref))?;
sys.run()?;

// a handler pins the exact cell version its message names
impl Actor for Pricer {
    fn handle(&mut self, cx: &Cx, env: &Envelope, req: PriceRequest) -> Reply {
        let curve = cx.pin(&self.curve)?;   // journaled: kill -9 safe
        price(curve.as_arrow(), req.tenor)     // zero-copy view
    }
}

// client side
let pricer = client.actor_ref::<PriceRequest>("pricer")?;
let reply  = pricer.ask(&req, timeout)?;        // or .tell(&evt)
  • State lives in cells, not actors. A curve, a book, a table of ticks — each is a versioned Arrow cell any actor can pin. Restarting an actor loses nothing, because it owned nothing.
  • The asker owns the reply memory. Learned from the demo, not the whiteboard: under crash-retry the reply must live in a chunk the asker allocated, named in the request — provably terminal, and handlers time-fence their writes at half the lease.
  • Failover is observable, not magical. Replies carry the incarnation and the exact redelivery count; the client that cares sees the crash; the one that doesn’t, never notices.

The substrate: shm-actors

  
One copy in. Zero copies after.

  
Holon does not carry its own runtime tricks — it stands on shm-actors, a
  substrate where a payload is serialized once into size-class pooled chunks and everything
  downstream moves a 24-byte, generation-checked descriptor. A coordinator owns
  names and leases, passes segment fds over a Unix socket, and is never on the data path;
  actors map their segments and stop making syscalls.


  

    
shm-ring Pub/sub
SPMC broadcast ring with per-subscriber cursors. One-way hop: 83.5 ns p50, cross-process — the same as cross-core.
How it works →

    
shm-task Tasks
MPMC queue with O(1) claim at capacity 256 and 65 536, leases, redelivery counts, and a journaled crash story. Holon's mailbox.
How it works →

    
shm-artifact Versioned cells
RCU-versioned Arrow tables: pin in ≤ 1 tick at any history depth, append in O(new data), windowed retention, exact delta reads. Holon's memory.
How it works →

    
shm-stream Streams
Transactional writers: stage many Arrow batches invisibly, install them as one atomic version. Abort or die — nothing partial is ever visible.

Safety is Rust's ownership story made multi-process: exclusive loans for
  writers, pinned shared views for readers, reclamation driven by leases + a per-actor
  borrow journal + generation counters. A process that dies mid-anything is unwound by
  replay, not by hope.

Why trust it

  
Adversarial by policy

  

    
239 tests that attack
Lineage races, crash replays, and exact-census invariants: count the free chunks after every hostile scenario and the difference must equal the live data — to the chunk.

    
4 loom models
The pin hazard handshake and the one-election reclaim CAS are exhaustively model-checked — and shown to fail against deliberately broken orderings.

    
5 fuzz targets
Every untrusted-input parser: manifest bytes, chain walks, Arrow layout, wire protocol. Plus a 200 000-iteration in-crate property test so the guarantee holds on stable.

    
Frozen, asserted ABIs
const offset assertions on the envelope, magic + generation checks on every dereference, torn-tail-tolerant journals.

  

  
Wording rules are part of the engineering: “zero-copy” is defined, the
  timer floor is named, memcpy throughput is not called ingestion, no comparison baseline exists so
  no “N× faster than X” is claimed, and a bench that can't distinguish two designs is replaced
  rather than quoted.






  
Get started

  
Run it in three commands

  
# build + the full adversarial test suite
cargo build && cargo test --workspace

# measured numbers on your machine (prints its own hardware profile)
cargo run -p shm-bench --release -- all

# the Holon demo: curve publisher, pricer + risk actors, clients,
# and a supervisor that kill -9s a pricer mid-message
cargo run -p holon-demo --release -- bench
